# Image Gallery

A modern and responsive Image Gallery website built using HTML, CSS, and JavaScript.

## Features

- Responsive image gallery
- Clean and attractive design
- Image preview
- Interactive user interface
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Run it in a web browser.

## Project Description

This project displays images in a clean and organized gallery layout with interactive features and responsive design.
